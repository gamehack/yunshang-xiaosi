# M2.3｜ULTRA 临水茶室—庭院垂直切片计划

版本：1.0｜日期：2026-11-13｜状态：已建立执行基线，资产制作待启动

## 1. 目标与边界

产品方向 A：沉浸式数字休闲空间。ULTRA 是质量目标，定义为商业独立游戏级的完整环境表现，不等于无预算的照片级资产，也不接受“Blender 单张静帧漂亮、浏览器运行效果不达标”。

首个交付只覆盖**临水茶室—庭院垂直切片**：从庭院主路接近茶室，穿过檐下空间，能够看到池塘、岸石、水生植物、竹木前景和远景层次；访客角色可正常漫步、转向、坐下/起身并保持既有存档。切片应包含建筑、地表、植物、太湖石、水、光照、材质、人物和实时镜头，是未来扩展整园的质量样板。

本阶段不扩地图，不重写 Three.js，不重做导航/A*/碰撞/座椅锚点/存档/音景状态机；不加入天气、昼夜、多人、账号、任务或商业化。美术替换必须保持可见几何与现有通行/碰撞/座椅空间一致。

## 3. 美术质量标准

### 3.1 建筑
- 尺度以 1 Blender unit = 1m；以访客身高、座面高度、门洞净高和柱间距校准。
- 茶室须体现可解释的结构层级：柱础、柱身、梁枋、檩、椽、檐口、屋脊、瓦垄、滴水/封边、门窗格栅；构件接缝合理，不允许悬空、互穿、无支撑。
- 灰泥墙、青灰黛瓦、木材、石材的色彩与粗糙度区分明确；避免纯色塑料感。

### 3.2 植物与山石
- 竹秆有节间、粗细变化和自然倾斜；叶片有分枝层级、叶簇疏密和轮廓变化。
- 树冠必须能读出枝干/冠层关系；灌木和地被分层，不以重复球体堆叠。
- 太湖石优先制作有主峰、孔洞、凹槽和负空间的轮廓；正面、侧面、逆光剪影都可辨识，不用随机多面体直接冒充完成资产。
- 植被不得侵入主通行带或持续遮挡人物；近景遮挡策略应在实时相机下验证。

### 3.3 地表、水与光
- 铺地按步幅和构造逻辑排布，石板/青砖/苔藓/泥土/岸石的纹理尺度一致，不允许明显重复平铺。
- 水面先采用低成本法线扰动、局部高光和可控倒影提示；避免全屏实时反射/SSR。水岸必须自然过渡，水生植物和岸石分布有疏密。
- 自然光以柔和斜阳和环境补光为基础；阴影清晰但不过黑，避免过度 AO、过曝、色偏和阴影 acne。
- PBR 参数必须在 Three.js 最终光照中校准，不以 Blender 材质球单独验收。

### 3.4 人物与空间叙事
- 现有角色先作为尺度尺和交互主体保留；不要求影视级面部写实。服装、比例、材质必须融入场景。
- 至少验收：入口/庭院接近、茶室檐下、面向池塘、侧身坐姿、起身继续漫步五种状态。
- 画面主次应形成近景（竹枝/岸石/窗框）、中景（人物/茶室/水岸）、远景（墙后树冠/亭台/树影）的层次；不得只堆装饰物。

## 4. 资产生产规范

- 工具：Blender 5.2.4 LTS；导出 GLB/glTF 2.0；运行时 Three.js GLTFLoader。
- 坐标：米制、Z-up；资产落地基准 Z=0；正面按现有管线约定 -Y；导入 Three.js 后复核 Y-up 与朝向，不允许靠运行时随意缩放修正错误资产。
- 每个可复用资产保留 .blend 源文件、生成脚本（若程序化）、.glb 导出文件、预览截图、尺寸/三角面/材质/贴图报告、版权/来源记录。
- 命名：category_asset_variant_vNN，如 architecture_teahouse_main_v01、rock_taihu_cluster_a_v01、vegetation_bamboo_clump_b_v01。
- 资产目录：art/blender/<category>/ 保存源文件；art/runtime/<category>/ 保存经审查的运行时 GLB；docs/evidence/m23/<asset>/ 保存截图与报告。临时导出放 artifacts/，不得直接进入生产加载路径。
- 模型拆分按可见性、材质和复用频率组织；避免一个建筑拆成数百个小 mesh，也避免整园合成一个无法剔除的大 mesh。
- 材质统一采用可移植 Principled BSDF / glTF PBR；复杂节点先烘焙。贴图按用途使用正确色彩空间；纹理尺寸以 1K/2K 为主，近景主资产可评估 4K，但必须有性能理由。
- 重复植物、瓦件、石板采用实例化或合批；评估 KTX2/Basis 与 Meshopt 后再决定引入，不把压缩引入作为首批阻塞。
- 不使用许可不明的模型、照片、贴图、音频。每项记录作者/来源、许可版本、署名、修改与再分发条件；参考照片仅作构图研究，不直接打包或描摹复制。

## 6. 性能原则与调优顺序

1. 先确认实际瓶颈，再优化；记录 GPU、CPU、帧时间分布和机位。
2. 先减少重复 draw calls、阴影投射物和过大透明覆盖，再做几何简化。
3. 对远景做 LOD/简化材质；近景保留高细节，远景优先轮廓和层次。
4. 控制实时阴影覆盖范围和分辨率；低画质减少阴影/纹理/植被密度。
5. 纹理优先压缩和按需加载；避免启动时加载全园全部高分辨率纹理。
6. 禁止用云端软件渲染 FPS 代表真实 PC 性能；SwiftShader 只作为功能回归环境。
