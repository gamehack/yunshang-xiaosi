# 半日闲 M2.0 · 云端 Codex 执行路线图

更新：2026-11-11。**唯一有效的 M2.0 开发任务清单**。本文件为计划，勾选只能依据代码、测试、CI 和验收证据；已有代码不等于真机验收通过。

## 产品边界
无注册、无任务/积分/排行榜、无聊天/多人/宗教仪式；浏览器第三人称苏式园林休闲漫游。核心路径：园门→庭院→茶室→竹林步道→望湖台→原路折返。用户可漫步、静坐、主动开启自然音景。P2 天气/季节/账号/联网/商业化不属于本次开发，不得擅自扩大范围。

## 平台与验收优先级（最新决策）
- **PC 优先**：桌面 Chrome/Chromium 为 M2.0 P0，Edge 为 P1，iPhone Chrome/Safari 与手机手势为 P2 非阻塞。
- **云端浏览器测试为必须尝试的开发步骤**：优先使用环境提供的浏览器/Playwright，启动 Vite 页面，实际操作并保存截图、控制台与网络错误、操作结果。浏览器不可用须提供环境错误证据并记录阻塞，不能写成通过。
- PC 性能目标：目标 60 FPS、P95 ≤16.7ms，记录测试硬件、分辨率、DPR 和场景；云端软件渲染数据仅作回归参考，不替代真实 PC 性能。

## 持续开发协议
1. 从 G0 开始，能自主解决的问题直接修复；每个可独立回归的批次执行“实现→测试→构建→同步文档→commit→push develop→核验 CI”。
2. 一个批次失败先自行诊断和修复；不可恢复时记录阻塞与证据，继续无依赖任务；不得无限重试或跳过测试伪称通过。
3. 云端 Codex 任务运行时长由平台决定；结束前必须提交进度与下一任务，后续任务可据此继续。不能承诺平台限制外自动执行。
4. 任何开发新需求必须与 PRD 的 P0/P1 边界一致；P2 功能不纳入本次。
5. 完成状态以证据为准，不按代码行数或提交次数判定。最终用户只需一次集中验收。
