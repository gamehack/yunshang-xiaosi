- 保留 TypeScript + Three.js + Vite，保留现有路线、碰撞、座位锚点、存档、音景和 WebGL 恢复行为。
- 优先增量修改、复用材质/几何、InstancedMesh；不要用更换框架或重建整个世界解决美术问题。
- 每个独立批次：实现→单测→构建→浏览器视觉/交互→更新文档→commit/push develop→检查 CI。
- 云端执行环境有时限时，结束前更新 `docs/EXECUTION-STATUS.md` 保存 SHA、证据、下一任务；不得要求用户每批次回复 go。
