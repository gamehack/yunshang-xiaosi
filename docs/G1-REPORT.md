- 寻路先验证实际起点/终点和有限坐标，再验证网格锚点及每段连续路径。保留非整数精确终点，补同格内行走，避免取整把池塘点当成桥面。

- 拒绝无效帧时长，单次模拟时间上限 0.1 秒，移动按不超过 0.1 米子步检查，避免长帧穿越门柱。非法站立坐标回退到入口 `(0,1,8)`；坐姿不使用站立障碍约束。
- 到达路径点时走完剩余距离，修复原先提前 0.14 米结束导致终点不准确和转角截断的问题。
