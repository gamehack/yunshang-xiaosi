# 半日闲 · 现行产品需求（PRD 2.0）
更新：2026-11-11。状态：已确认方向与实施范围；各里程碑完成度以 CHANGELOG / ACCEPTANCE 为准。

## 产品定位
无需注册即可进入的第三人称浏览器 3D 苏式园林与山野休闲空间。以园门、庭院、茶室、竹林步道、望湖台为连续漫游路线；用户可漫步、驻足、静坐、听自然环境音。**无任务、等级、排名、宗教仪式、强制社交、聊天或多人房间**。旧版「云上小寺」的木鱼、合十、多人房间等内容已废弃。

## 核心用户体验
1. 手机或 PC 打开网页，不注册即可看到可交互园林；明确加载状态及失败回退。
2. 手机轻点地面寻路、拖动旋转、双指缩放；PC WASD/方向键、鼠标拖动及滚轮。
3. 从园门经园林与茶室，沿竹林步道抵达望湖台，可停留、坐下、起身、返回入口。
4. 休息时可主动开启或关闭自然音景；不强制自动播放音频。
5. 本地续游保存位置、镜头、有效坐姿及偏好，存储不可用时不阻断使用。

## 功能分级
### P0：基础稳定
- 第三人称镜头不明显穿墙/屋顶；植物近景遮挡可控，镜头恢复平滑，无明显抖动。
- 触屏点击与拖动不混淆；双指缩放、失焦恢复、停止行走可靠。
- 导航不穿墙、不落水；入口至望湖台路线可达并可折返。
- HUD 安全区、加载与错误状态、画质档位、性能读数、游客存档、WebGL 恢复。
- CI、性能基线、文档同步与集中生产发布。

### P1：园林美术与沉浸
- 苏式白墙黛瓦、屋脊檐口、木构与格栅；自然竹林、树木、灌木、景石、铺装、水岸。
- 正式人物模型与基本行走/转向/坐下动画；真实座椅锚点。
- 自然音景、静音/音量控制、轻量引导与场景停留体验。
- 场景资源复用、按需加载及移动端画质降级。

### P2：后续增强（不得阻塞核心体验）
- 昼夜、天气、季节、扩展山野地形、更多场景及精细化环境反馈。
- 是否引入联网功能、用户账户或商业化，需独立产品决策。

## 非功能目标（目标，不是实测）
- 以中端 iPhone 30 FPS 为最低目标，45–60 FPS 为优化目标；P95 帧时间优先控制在 33ms 内。
- 低端设备应有省电档与清晰的降级路径；无 WebGL 或资源加载失败时显示可理解的提示。
- 不采集不必要的个人信息；素材必须原创或有明确授权。
- 中国大陆公开运营前完成适用监管、版权、备案及隐私评估；CI 通过不等于合规完成。
