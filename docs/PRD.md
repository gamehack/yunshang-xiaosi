# 半日闲 · 现行产品需求（PRD 2.0）
更新：2026-11-11。状态：已确认方向与实施范围；各里程碑完成度以 CHANGELOG / ACCEPTANCE 为准。

## 最新美术方向（2026-11-11，优先于旧版本）
用户明确选择 **A：写实苏州园林**。此前低多边形/玩具化美术方向已被否决。现行美术实施计划为 [M2-2-REALISTIC-SUZHOU-GARDEN.md](M2-2-REALISTIC-SUZHOU-GARDEN.md)。保留现有业务逻辑，重建视觉表现层；以真实建筑比例、PBR 材质、自然植物、水面、山石、光照和移步换景为目标。PC 优先；不得继续以低模作为最终美术验收标准。

## 产品定位
无需注册即可进入的第三人称浏览器 3D 苏式园林与山野休闲空间。以园门、庭院、茶室、竹林步道、望湖台为连续漫游路线；用户可漫步、驻足、静坐、听自然环境音。**无任务、等级、排名、宗教仪式、强制社交、聊天或多人房间**。旧版「云上小寺」的木鱼、合十、多人房间等内容已废弃。

## 平台优先级（2026-11-11 最新决策）
**PC 浏览器为首发主平台，Chrome/Chromium 桌面端是 P0 验收对象。** Edge 为 P1 兼容性；手机触控与 iPhone Chrome/Safari 为 P2 适配，不阻塞 PC M2.0 RC。保留已实现的移动端能力，不为此轮主动删除。云端 Codex 应使用其可用浏览器或 Playwright 实际运行和截图验证 PC 页面；无法使用浏览器时明确记录缺失，不能视为通过。

## 核心用户体验
1. PC 或手机打开网页，不注册即可看到可交互园林；明确加载状态及失败回退。
2. PC 使用 WASD/方向键、鼠标拖动及滚轮；手机保留轻点寻路、拖动旋转、双指缩放作为后续适配。
3. 从园门经园林与茶室，沿竹林步道抵达望湖台，可停留、坐下、起身、返回入口。
4. 休息时可主动开启或关闭自然音景；不强制自动播放音频。
5. 本地续游保存位置、镜头、有效坐姿及偏好，存储不可用时不阻断使用。

## 功能分级
### P0：基础稳定
- 第三人称镜头不明显穿墙/屋顶；植物近景遮挡可控，镜头恢复平滑，无明显抖动。
- 触屏点击与拖动不混淆；双指缩放、失焦恢复、停止行走可靠。
- 导航不穿墙、不落水；入口至望湖台路线可达并可折返。
- HUD 安全区、加载与错误状态、画质档位、性能读数、游客存档、WebGL 恢复。
- CI、性能基线、文档同步与集中生产发布。

### P1：园林美术与沉浸
- 苏式白墙黛瓦、屋脊檐口、木构与格栅；自然竹林、树木、灌木、景石、铺装、水岸。
- 正式人物模型与基本行走/转向/坐下动画；真实座椅锚点。
- 自然音景、静音/音量控制、轻量引导与场景停留体验。
- 场景资源复用、按需加载及移动端画质降级。

### P2：后续增强（不得阻塞核心体验）
- 昼夜、天气、季节、扩展山野地形、更多场景及精细化环境反馈。
- 是否引入联网功能、用户账户或商业化，需独立产品决策。

## 非功能目标（目标，不是实测）
- 以中端 PC 桌面 Chrome/Chromium 为性能基线：目标 60 FPS，P95 帧时间优先 ≤16.7ms；低配 PC 应提供省电档和降级路径。实际目标须结合测试硬件记录，不以云端虚拟 GPU 的 FPS 代表用户设备。移动端指标属于后续 P2 验收。
- 低端设备应有省电档与清晰的降级路径；无 WebGL 或资源加载失败时显示可理解的提示。
- 不采集不必要的个人信息；素材必须原创或有明确授权。
- 中国大陆公开运营前完成适用监管、版权、备案及隐私评估；CI 通过不等于合规完成。
