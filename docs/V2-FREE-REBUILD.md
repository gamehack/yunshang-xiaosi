## 原始决策与约束

- 产品：PC Chrome/Chromium 优先的可漫游、可停留的苏州园林休闲空间；第一垂直切片仅做“半日闲·临水茶亭”。
- 审美：**自然主义半写实、苏州古典园林空间语言**。不接受低多边形/玩具风格充当最终效果；用户保留最终美术验收权。
- 预算：软件许可费 0 元起；只采用可验证授权、免费商用且允许分发的素材；不使用收费生成 API、付费素材或必须购买的 3D 编辑器。
- 开发：ChatGPT 直接经 GitHub 连接器管理代码、经 Cloudflare 连接器管理部署；不依赖 Codex。浏览器视觉验收优先使用可执行浏览器环境；普通聊天无法直接控制用户 Windows 本地 Blender/浏览器。
- 原始部署策略：V2 隔离开发、未获发布授权不合并 main。**此策略现已被 2026-11-13 的单 main 决策取代。**
- 原始技术方向：Three.js + TypeScript + Vite；GLB/glTF、PBR 材质、色彩管理、环境光照、软阴影、按需加载、LOD/实例化、可控水面反射。
- 首先建立固定机位的园林高保真场景，再增加第三人称漫游、碰撞、坐姿、存档和音景。

## 样板场景范围（原始方案）

- 仅一处临水茶亭及相邻约一屏景深：白墙黛瓦、合比例木构、池水与岸线、两类植物层次、自然点景石、月洞门或漏窗、石板路径、自然光。
- 构图以亭和池为视觉中心，明确前景/中景/远景、借景/框景。
- 视觉否决项：塑料材质、重复圆锥树、简单几何体假山、明显穿模、建筑结构不合理、模型来源不明。
- 技术验收：1920×1080 和 1366×768 浏览器截图、可旋转镜头/近景观察、WebGL 错误检查、加载体积和 draw calls/帧时间记录。真实 PC 60 FPS/P95 16.7ms 是目标，不是现有实测结论。
