# 半日闲 M2.2｜写实苏州园林美术重建执行计划（现行唯一美术计划）

决策：2026-11-11 用户明确选择 **A：写实苏州园林**，否决此前低多边形/玩具风格。状态：计划批准，尚未据此完成美术重建。**本计划取代 M2.1 低多边形局部修复路线**；已有 M2.1 工作仅保留经验证有用的镜头/交互/稳定性修复。不得沿用“保持低多边形”作为新美术目标。

## 产品目标与验收原则
- PC Chrome/Chromium 为 P0，Edge P1，手机 P2。目标是能令人沉浸欣赏的苏州古典私家园林，而非抽象低模 3D 演示。
- 真实园林美学：白墙黛瓦、曲折回廊、月洞门/漏窗、亭台水榭、太湖石、自然竹木、池水、借景/框景/障景、移步换景；参考拙政园、留园、网师园的**空间语言**，不声称复刻任何具体园林。
- 不只是提高多边形：建筑结构与尺度、植物生态形态、材质粗糙度/法线、自然光影、层次构图和水岸关系必须整体统一。
- **必须有真实浏览器前后截图与动态体验证据**。测试通过不等于美术验收；由用户最终审美决策。

## 技术路线
保留 Three.js + TypeScript + Vite、现有导航/碰撞/座椅/存档/音景/镜头状态机；允许重构或替换**视觉表现层**，禁止为美术升级重写业务逻辑。使用 glTF/GLB 场景资产、PBR（MeshStandard/PhysicalMaterial）、烘焙光照/环境贴图（依法取得）、LOD、实例化、纹理压缩/按需加载、分级画质。允许原创 Blender 建模（可通过脚本批量生成）或来源清晰且许可允许再分发的免费资产；不允许未核实版权的网上下载、直接复刻照片或依赖付费素材。资产清单记录来源、作者、许可、修改、文件大小；缺素材时优先原创，绝不虚构授权。
