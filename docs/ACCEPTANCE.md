## 证据记录
每项完成必须写明：commit SHA、测试文件/命令及结果、CI URL、浏览器/设备、场景路径、截图/视频链接（如有）、已知缺陷。没有执行的项目不得填写“通过”。

## 发布闸门
1. A01–A05、A09、A13、A16–A18 的可自动验证部分不得存在已知 P0 阻断缺陷。
2. A06–A08、A10–A12、A14–A15 需要真实设备/浏览器证据；云端无法完成则保留待用户集中验收。
3. A19 是中国大陆公开运营前的独立人工审查；不得通过 CI 替代。
4. A20 仅在用户明确授权后执行；完成 M2.0 RC 不代表已经生产发布。
