# 半日闲视觉规范（M0.9 开发基线）

> 本文件替代旧版寺院、僧人、2.5D 固定镜头视觉规范。M0.9 尚在 develop，未发布。

## 产品美术方向

- 非宗教、无任务的苏式园林与苏州山野休闲体验；风景是主角，人物仅承担漫游。
- 园林：白墙黛瓦、茶室、亭台、假山、池塘、石板路、竹林；外部：竹林长路、湖边望湖台。远期扩展符合苏州地理与物候的山野田园。
- 当前使用低多边形、低饱和、柔和自然光的原创程序化几何；不宣称真实复刻具体园林。
- 当前参考色：墙 #e9e7df、屋顶 #4e5653、石路 #c7bda9、木构 #765d48、池水 #729f9b、地面 #b3bea7。
- 镜头：第三人称可旋转、可缩放；手机单指点击行走、拖动旋转、双指缩放。

## 当前实现与差距

- M0.8 生产版：基础白模、木桥、茶室、亭子、竹林、湖面，胶囊体人物。
- M0.9 开发版：双色双层树冠、木格栅与屋檐层次、石板路、静态水纹和岸线过渡。
- 未实现：真实竹叶结构、苏式瓦片与坡屋顶、自然不规则水岸、正式人物模型、精细地形、天气物候和动态水面。
- M0.9 视觉修改仍需手机 Chrome 与 PC 浏览器实测，不能仅凭 CI 宣称视觉验收通过。

## 手机 UI

- M0.9 手机端 HUD 默认收起，标题和“展开”按钮保持可见；展开后显示操作提示、性能指标、坐下、回到入口、停止行走和画质切换。
- 保持可触达、可聚焦和足够文字对比度；不要用大面积 HUD 遮挡园林。
- 画质档位：省电 DPR 上限 1，均衡 1.5，精细 2；实际 FPS 以设备实测为准。

## 资产和性能原则

- 原创或合法授权；避免照搬真实园林的受保护摄影、模型。
- 优先复用材质和几何体，重复植物、桥面与铺装使用 InstancedMesh。
- 美术效果必须兼顾手机帧时间、Draw Calls、三角形规模和内存，不能仅追求静态截图。
