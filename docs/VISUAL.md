# 视觉规范 v1.0

- 2.5D 等距斜俯视，固定镜头，微缩卡通，暖色柔和光照；手机竖屏优先。
- 主色：寺院朱红 #A94736；暖金 #D8AF69；松绿 #617761；石米 #E8DCC6；深灰绿 #323B37。
- 场景：山门入口、庭院步道、主殿背景、木鱼交互区、静坐蒲团区、银杏树。主殿不开放室内探索。
- 角色：中性化圆润小和尚形象（题材待合规）；待机、行走、敲击、合十、静坐五种状态；统一光源与阴影方向。
- UI：顶部在线人数/音量/退出；底部按上下文出现动作按钮；静坐时 UI 淡出；禁止聊天框和任务列表。
- 原创素材：建立角色母版、场景 tile atlas、动画 sprite atlas、音效清单及版权记录；不得直接复制 Sansa 素材。
- 性能：移动端低纹理开销、图集复用、首屏资源分包；设置减少动态效果选项。
- 合规保留替代设计：如寺院/僧人/仪式被判定不适宜公开运营，替换为非宗教中式庭院、普通访客和纯休息动作。

此文档为设计约束，不代表视觉母版已验收。
