# G2 人物、座面高度与动作执行记录

日期：2026-11-11。工作分支 develop；提交、CI 和浏览器视觉证据由主执行任务统一记录。

## 改动

- 将整段旋转腿改为髋→大腿→膝→小腿→鞋的程序化关节层级，共享腿部几何和材质。局部 +Z 为人物前方与坐姿膝盖朝向。
- 新增骨盆实体，站立基准脚底 y=0，根高度仍为 1；坐下根高度由真实座面加骨盆接触偏移计算。茶座中心保留 `(-8,-8.3)`，座面 y=0.59；湖座座面 y=0.875。旧的固定坐姿根高度 0.69 已删除。
- 坐姿大腿前屈，小腿保持竖直。低茶凳稍抬膝以让鞋底位于地台上；高湖凳允许自然垂足，鞋底始终高于望湖台。坐起过渡过程中根据腿部实际变换计算最低鞋底，需要时抬高根节点以防穿地。
- `world/layout.ts` 新增 `walkSurfaceHeight`，直接读取共享桥板、茶室地台、望湖台尺寸，返回平桥顶 0.18、茶室地台顶 0.245、望湖台顶 0.3。站立根高度据此更新。无新增拱桥或视觉假高差。
- 茶凳/石凳座面几何与 SeatAnchor 的 surfaceY 均引用 `SEAT_GEOMETRY`；茶室地台构造引用共享地台高度，避免角色与场景分别维护同一高度。
- 新增最短角度指数阻尼 `turnVisitor`；坐起与朝向过渡均按 dt 运行，保持整体人物缩放为 1。
