# M2.0 RC 性能与持续运行记录

## 云端参考环境（不是目标 PC）

- x86_64，AMD EPYC 9V74，环境暴露5个逻辑CPU；Chromium 156.0.8078.79。
- 强制 ANGLE/SwiftShader 软件渲染，无真实用户GPU验收。
- 功能截图：1280×720、DPR=1、初始均衡；切换精细/省电已验证。
- 持续运行：960×600、DPR=1、均衡，从入口开始，5分钟W北行、5分钟S折返，真实墙钟至少600秒，逐30秒记录位置、HUD、CDP JSHeapUsedSize。
- 脚本：`TEST_URL=http://127.0.0.1:4173 npm run test:soak`；测试以页面异常、实际进入z<-90、回到z>=0为失败条件。
- 软件渲染读数受虚拟CPU和并行进程影响，既不能证明达标，也不能证明用户PC无法达标。

最终输出保存在 `docs/evidence/rc1/soak-report.json`（完成后归档）；性能目标仍为真实PC优先稳定60FPS、P95≤16.7ms。
