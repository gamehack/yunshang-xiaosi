# M2.0 素材与隐私边界

2026-11-11。此为工程清单，不是法律合规结论。

- 建筑、人物、植被、石板、池塘、远山均为本仓库程序化几何，无外购或下载美术。
- 风声由 Web Audio 本地合成，无外部音频、版权不明媒体或自动播放。
- 运行时依赖 Three.js（MIT）；Vite/TypeScript/Vitest/Playwright 为开发工具。发布时保留依赖许可要求，独立审查公共分发的第三方声明。
- 字体使用系统字体，不连接字体 CDN；静态构建不调用天气、账户、分析、广告或聊天 API。
- 游客续游和画质仅存浏览器 localStorage；清除网站数据会移除这些偏好，无云同步。浏览器拒绝存储时仍可游玩。
- Cloudflare 托管层访问日志、地区数据处理条款与最终隐私声明由运营者确认。

## 仅人工可确认的发布闸门
1. 实际运营地域的适用监管分类、备案及其他要求。
2. 项目与第三方许可证、名称及发布素材的最终版权审核。
3. 托管日志和隐私告知的准确性。
4. 最终真实 PC 体验及硬件性能验收，然后才可授权合并/发布。

未擅自合并 main 或发布生产。
