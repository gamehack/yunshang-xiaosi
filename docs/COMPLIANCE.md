# G0 合规预审（非法律意见）
日期：2026-11-11；状态：**未通过，待主管部门/专业法律确认**。

## 已确认的法规风险
《互联网宗教信息服务管理办法》（2022-03-01 施行）第六条：向公众提供宗教文化等信息的服务可能需要许可；第十七条：限制互联网组织宗教活动及宗教仪式传播；第十八条：禁止网上设立宗教活动场所；第十九条：禁止以宗教名义募捐。
官方原文：https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2022/art_36c84b53178948ffba50dffaa7503cb1.html

## 当前产品高风险元素
- 「云上小寺」名称、虚拟寺院和僧人身份：是否被认定为互联网宗教信息服务/虚拟宗教场所？
- 木鱼、合十、祈愿：是否构成线上宗教仪式或活动？
- 多人共处：是否产生组织宗教活动或传播平台性质？
- 若游戏化：是否涉及网络游戏运营、出版审批、未成年人保护等要求？
- 中国大陆服务：ICP备案/许可、网络安全及个人信息合规、云服务可用性。

## G0 必做
1. 制作功能级风险清单，向上海市相关主管部门或熟悉互联网宗教与游戏业务的律师咨询。
2. 对「名称、场景、木鱼、合十、祈愿、多人」逐项取得明确风险结论，记录咨询依据。
3. 形成可运营版本的边界；如不适宜则替换为非宗教休息空间，保持匿名共处的用户价值。
4. 在 G0 签字通过前禁止公开发布、付费、捐赠或宣传为线上宗教场所。

目前仅完成法规文本初筛，**不得据此认定原方案合法可上线**。
