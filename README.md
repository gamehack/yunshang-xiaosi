# 云上小寺 (yunshang-xiaosi)

> 人间纷扰，来寺里坐坐。

独立消费级 Web 产品：匿名进入 2.5D 微缩卡通虚拟中式寺院，漫步、静坐、木鱼与多人无声共处。

**状态：M0 设计与合规预审；尚未开发、尚未部署。** 私有仓库。

## 产品约束
- 中国大陆首发；手机 Web 优先；匿名直接进入
- 单场景、单角色、无文字聊天、无排行榜、无签到、无收费
- 不宣称宗教功效，不冒充真实宗教场所
- 互联网宗教信息服务及网络游戏合规分类未明确前，禁止公开上线
